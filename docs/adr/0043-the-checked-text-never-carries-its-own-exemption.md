# The checked text never carries its own exemption

Two consecutive waves produced the same shape in two different guards: a row authored content that legitimately *names* a path, the guard read that string as a *citation* it must resolve, and the row reworded around it — both times the content was right, both times the guard was right in isolation, and both times the workaround silently narrowed what a row is able to say. Occurrence 1 (disclosure 494.1): a docs row teaching the setup scaffold could not cite `.claude/hooks/echo-guard.cjs` — real in every consumer repo, deliberately never scaffolded in flotilla's own clone — so the landed text hides the path inside a multi-word command span the bare-path regex cannot match, and describes it in prose elsewhere. Occurrence 2 (disclosure 542.1): a spec's doc-comment named a planted fixture under `.claude/skills/`, absent by design; the worker renamed the fixture to `.txt` at six sites, exploiting the extractor's `.md` requirement and trading fixture realism for guard silence. Filed as #555; triage established the ground: three rules across two files whose only shared piece is one `existsSync` line at an anchor, no shared module, and existing hatches that already sort along absence semantics — a gitignored absent-by-construction prefix filter, an allowlist whose entries must be deleted the moment they start resolving, a whole-file exemption pinned by test at exactly one entry, a placement table documented as a shrinking ratchet.

## Decision

1. **The checked text never carries its own exemption.** No inline marker, no magic comment, no naming convention whose purpose is to switch a guard off from inside the guarded corpus. The reasoning is the ADR-0034 Amendment's, one seam over: an author under a failing constraint escapes through whatever field it still controls, and both live occurrences show exactly that — each worker invented a silent form-dodge (a command span, a file extension). An explicit marker would not tame the dodge, it would legitimize it, and a forgotten marker fails exactly as today. Exemptions live guard-side: named classes with semantic docstrings, pinned or self-policing, in the guard's own file — where adding one is a loud, reviewed change instead of a quiet edit to the text under test.
2. **"Real in the other form" becomes a paired, self-policing class.** The bare-path rule gains consumer-scaffold entries as pairs — installed-form path ↔ source-form counterpart (ADR-0032 vocabulary): the cited consumer path must **not** resolve in the clone (an entry that starts resolving must be deleted — the same discipline the anchored-link allowlist already enforces), and the vendored counterpart **must** resolve (a pair whose source file vanished goes loud instead of teaching a stale location). First entry: `.claude/hooks/echo-guard.cjs` ↔ `tools/wave/hooks/echo-guard.cjs`. The occurrence-1 rewordings are reverted wherever the text wants the real path.
3. **Deliberately-unreal paths build nothing new: the code-line doctrine is the mechanism, the failure message becomes the teacher.** Code lines are data, comment lines are citations — the shipped-citation guard already keeps its *own* planted fixtures invisible exactly this way, so a realistic `.md` fixture in a string literal has always passed. What failed was discoverability at the moment of pressure, and the proximal-teaching lesson is freshly measured (#556: a general clause above does not hold, a specific hint at the failing spot does). The dead-citation failure message therefore learns to name the two sanctioned answers — a fixture belongs in code lines; a comment names its subject, not the path — beside the "name its subject instead" teaching rule 2 already carries. The `.txt` rename is reverted to a realistic `.md` fixture living in code lines. Rule 4 keeps today's strictness on comments deliberately: a dead-looking path in a comment invites the reader to chase it, so naming the subject there is better prose, not a lost capability.
4. **The citation-placement ceiling is out of this class — already answered.** It is bumped by an *identifier in narrative position*, never by a path; its predicate is position, not existence; and the sanctioned remedy (the trailing parenthetical) is Convention 14 doing precisely what it exists for. Nothing was lost, nothing accumulates invisibly, no ticket.

## Considered Options

- **An inline subject-marker taught to all four extractors** (rejected) — the author-controlled escape, per the ADR-0034 Amendment logic and the #556 measurement; would additionally need a shared module across two files that share one line *by documented design*; and its failure mode (a forgotten marker) is byte-identical to the status quo.
- **Context-sensitivity — teach the guards which positions are citation positions** (deferred, not rejected) — the ticket's own assessment stands: the most useful answer and by far the hardest to get right, a wrong split worse than no split, zero prior art on the two rules that fired. The named classes do not preclude it later.
- **A fixture namespace or a pinned fixture allowlist** (rejected) — structure for a class whose single live occurrence demonstrably did not need it: the sanctioned mechanism existed and was merely undiscoverable. Building it would invert ADR-0034 — a promotion before the prose tier was ever tried at the right spot.
- **Accept and document** (partially adopted) — the comment-side strictness is accepted *and* defended as prose discipline. What is not accepted is the silent narrowing: the paired class restores the consumer path to teachable prose, and the teaching moves into the failure message instead of waiting to be rediscovered per row.

## Consequences

- #555's implementation scope: the paired consumer-scaffold class (both assertions), reverting both occurrence-1 rewordings (the command-span citation in `wave-setup/SKILL.md`, the descriptive stand-in in `setup-mechanics.md`), the failure-message teaching in the shipped-citation guard, and the six-site `.txt` → `.md` fixture revert in `worktree-cleanup.spec.ts`. Class (d) is explicitly out of scope. Closes #555, so it goes through a reviewed wave row (ADR-0033).
- CONTEXT.md gains **Citation** and **Subject path** (Distribution) — the vocabulary the guards, the DoR gate's narrative-only question, and the spine prose already use informally.
- Every future guard inherits the doctrine: an exemption is a guard-side named class, self-policing where an assertion exists to make it so; the guarded corpus never holds its own key.
- This ADR lands Coordinator-direct (ADR-0033: it closes no issue).
